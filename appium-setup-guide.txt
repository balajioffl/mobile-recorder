Adb device:

1. Install ADB

Download platform tools:
Android Platform Tools (Official)

cd ~
unzip platform-tools-latest-linux.zip
mv platform-tools android-tools
echo 'export PATH=$PATH:~/android-tools' >> ~/.bashrc
source ~/.bashrc

Check:

adb version

2. Enable Debugging on Phone

On your Android device:

Settings → About Phone → tap Build Number 7 times
Go to Developer Options
USB Debugging ON

adb devices

Start Raw Event Capture
adb shell getevent -lt

Filter Only Coordinates
adb shell getevent -lt | grep -E 'ABS_MT_POSITION_X|ABS_MT_POSITION_Y'

Capture Key Presses
adb shell getevent -lt | grep EV_KEY


Appium gives (UI-level info)
it understands the app structure
It gives:
    • Element ID (resource_id) 
    • Text inside element 
    • Button / input field info 
    • Class (Button, EditText) 
    • Content description 
    • Activity / screen name 
    • Element bounds (position + size)

ADB gives (Touch-level info)
It understands finger movement only
It gives:
    • Tap coordinates (x, y) 
    • Swipe start & end 
    • Scroll (as swipe) 
    • Long press duration 
    • Raw touch events
